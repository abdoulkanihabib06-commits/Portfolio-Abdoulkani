PORTFOLIO — ABDOULKANI HABIB ADEN

1. Décompresse le ZIP.
2. Ouvre le dossier dans Visual Studio Code.
3. Lance index.html dans ton navigateur ou avec Live Server.

À personnaliser dans index.html :
- Remplacer TON_EMAIL_ICI par ton adresse e-mail.
- Remplacer les href="#" de GitHub, LinkedIn et WhatsApp par tes vrais liens.

La section « Compétences académiques » reprend uniquement les unités
d'enseignement visibles sur la maquette Licence Informatique fournie.
Les enseignements sont regroupés par thème. Aucun langage, outil ou savoir-faire
extérieur à la maquette n'est présenté comme compétence académique.

Site réalisé en HTML, CSS et JavaScript, sans framework.
